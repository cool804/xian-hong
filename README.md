# Engineer x Designer Button Demo

A simple GitHub Pages ready web page built from the provided UI requirement.

## Files
- `index.html`
- `style.css`
- `script.js`

## What it does
- Shows one main image area
- Places a small rounded button near the image
- Reveals detailed information below the image when clicked
- Does **not** implement the left image list, matching the requirement

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** branch and **/root** folder.
6. Save and wait a moment.
7. GitHub will generate a public Pages link.
